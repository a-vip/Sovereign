# 🌐 Sovereign Marketing & Showcase Platform

**Sovereign** is the static, high-fidelity marketing front, product showcase, and client onboarding portal for the Sovereign ecosystem. Built with vanilla HTML5, CSS3, and modern JavaScript, it serves as the public landing presence for the enterprise platform and OSINT feeds.

The design utilizes a highly curated, dark Cyberpunk-HUD aesthetic—featuring HSL-tailored border glows, premium glassmorphism backdrops, and subtle micro-animations that deliver a premium, state-of-the-art interactive experience.

---

## 🎨 Showcase Layouts & Pages

The marketing platform contains dedicated, responsive pages designed for onboarding, product showcase, and conversions:

### 1. `index.html` (Corporate Command Hub)
*   The primary marketing landing page introducing the Sovereign platform.
*   Features a responsive header navigation, glowing pricing teasers, deep-tech branding assets, and high-impact call-to-actions.

### 2. `signals.html` (Intelligence Feed Mockup)
*   A premium, non-interactive, high-resolution feed interface representing live tactical OSINT bulletins.
*   Features CSS-based alert severity styling and grid telemetry cards mirroring active satellite and border monitoring reports.

### 3. `pricing.html` & `enterprise.html` (SaaS Tiers & Corporate Inquiries)
*   **Pricing Layout**: Beautiful, tiered comparison cards outlining the subscription levels (Tactical, Operational, and Strategic).
*   **Enterprise Layout**: A customized corporate query system designed for enterprise defense planners, legal advocacy centers, and intelligence agencies.

### 4. `checkout.html` & `success.html` (Payment Portal & Success Flows)
*   **Checkout Console**: Sleek, secure front-end mock interface featuring form validation, interactive HSL borders, dynamic subscription calculations, and glassmorphic inputs.
*   **Success Portal**: Elegant post-purchase validation showing system key generation processes and automated download links.

### 5. `about.html` (Mission Statement)
*   Detailing the ethical and operational frameworks of the Sovereign Algorithms Campaign, legal advocates compliance, and disarmament educational advocacy.

---

## ⚙️ Design Tokens & CSS Customization

The design system is managed globally inside `/css` styles sheets using pre-defined modern aesthetic tokens:
*   **Typography**: Outfitted with premium sans-serif typography (e.g. Google Fonts Outfit and Inter) rather than generic browser defaults.
*   **Colors**: Harmony-focused dark themes using sleek HSL configurations.
*   **Effects**: Vibrant glowing borders, glassmorphic box-shadow overlays, and interactive hover scales.

## 🛠️ Usage & Local Preview

1.  **Clone the Repository**:
    ```bash
    git clone https://github.com/a-vip/Sovereign.git
    cd Sovereign
    ```

2.  **Run Locally**:
    Since this is a high-performance static repository, you can run it directly by opening `index.html` in any web browser, or serve it using standard CLI packages:
    ```bash
    # Using Python:
    python -m http.server 8000

    # Using Node:
    npx serve .
    ```
